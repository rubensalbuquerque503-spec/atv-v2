# Sistema de Controle de Estoque em C

## Sobre o projeto

Sistema simples desenvolvido em linguagem C para controlar o estoque de uma loja.

## Funcionalidades

1. Cadastrar produtos
2. Consultar estoque
3. Registrar venda
4. Consultar produtos para reposição
5. Registrar entrada de mercadorias
6. Encerrar o programa e mostrar o valor total do estoque

## Tecnologias utilizadas

- Linguagem C
- Funções
- Vetores e matrizes
- Estruturas de repetição
- Estruturas condicionais

## Arquivos do projeto

- `main.c`: menu principal do programa.
- `back.c`: funções de controle do estoque.
- `back.h`: declarações das funções.
